# 0001: Project name

Status: Accepted

Date: 2026-08-11

## Context

複数のモデル、エージェント、API、MCP接続をひとつの環境で扱うプロジェクトに、正式名称が必要です。

## Decision

正式名称を **M.O.E. (Multi-Model Otaku Environment)** とします。`M.O.E.` は日本語の「萌え」にも掛けた名称です。

## Consequences

- ユーザー向け正式表記には `M.O.E.` を使用します。
- コード、package名、CLI名など記号を使いにくい場所では `moe` を使用できます。
- `DevRoom` は過去の仮称としてのみ扱い、新しい文書名、実装名、API名には使用しません。
