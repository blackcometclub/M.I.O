# Documentation

- `architecture/`: 比較中の設計、制約、調査結果。ここにあるだけでは決定ではありません。
- `decisions/`: プロジェクト所有者またはmaintainerが採用した判断と、その理由・影響範囲。
- `feasibility-report.md`: 実際の接続試験で観測した結果。
- `USER-GUIDE.md` / `USER-GUIDE.ja.md`: V1の導入、Provider login、手動update、backup、data境界、uninstall、troubleshooting。
- `RELEASE-NOTES-1.0.0.md` / `RELEASE-NOTES-1.0.0.ja.md`: 現行V1の機能、配布経路、既知の制約、更新状況。
- `HANDOFF_*.md`: 開発区切り時点の一時的な引継ぎ記録。現在の仕様はREADMEやADRを優先します。

事実、提案、決定を混ぜないことを基本ルールとします。
